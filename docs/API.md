# API

Authentication: `POST /api/auth/register`, `POST /api/auth/login`, `GET /api/auth/me`.

Research: `GET /api/targets`, `GET /api/targets/{name}`, `GET /api/mast/{target}`, `POST /api/analysis`, `POST /api/upload`.

Methods: `/api/simulate/transit`, `/api/simulate/radial-velocity`, `/api/simulate/direct-imaging`, `/api/simulate/biosignature`, `/api/simulate/gravitational-lensing`, `/api/uncertainty`.

Data: `/api/planets`, `/api/compare`, `/api/analysis`, `/api/analytics`.

User: saved targets, activity, comments and alerts.

Interactive Swagger UI is available at `/docs`.
